# Multi-Vendor Marketplace

A full-stack Multi-Vendor Marketplace built with Next.js.

## Features
- Customer Authentication
- Vendor Dashboard
- Admin Dashboard
- Product Management
- Shopping Cart
- Order Management
- Wishlist
- Reviews & Ratings
- Responsive Design
- Dark/Light Mode

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Supabase
- Node.js

## Installation

```bash
npm install
npm run dev
```
